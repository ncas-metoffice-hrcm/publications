# publications
Categorise and visualise peer-reviewed publications from HRCM using .bib files.

New publications should be added to the relevant .bib file:

***HRCM_core.bib*** — publications covering Met Office model development and underpinning capability.  
***UJCC.bib*** — publications from the UK–Japan Climate Collaboration, covering early model-development using the Earth Simulator.  
***UPSCALE.bib*** — publications from the UPSCALE project on resolution sensitivity using the Unified Model.  
***PRIMAVERA.bib*** — publications from CMIP6-HighResMIP and PRIMAVERA, the project that coordinated the European contribution.  
***EERIE.bib*** — publications from EERIE, the successor project to PRIMAVERA, and related km-scale modelling work (e.g., nextGEMS, DYAMOND).  

New .bib files may be created and added to *simple_pybib.py*.
